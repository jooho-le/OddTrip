# OddTrip 프론트엔드·백엔드 기능 차이

- 확인 기준: `origin/dev@abd56d8`
- 확인일: 2026-09-16
- 범위: 백엔드 미사용 기능, 백엔드 미지원 프론트 기능, 불완전 연결 기능, 양쪽 모두 미구현 기능

## 2. 백엔드에는 있지만 프론트가 사용하지 않는 기능

| 우선순위 | 기능/API | 현재 프론트 상태 | 필요한 작업 |
| --- | --- | --- | --- |
| P0 | `GET /api/trips/{tripId}` | 서비스 메서드만 있고 실제 여행 열기에서 사용하지 않음 | 여행 URL에 `tripId`를 포함하고 새로고침 시 같은 여행 복구 |
| P0 | `PUT /api/trips/{tripId}/preferences` | 공동 합의를 우회할 수 있어 의도적으로 사용하지 않음 | API 폐기 또는 내부 전용으로 제한하고 제안·수락 흐름만 허용 |
| P1 | `POST /api/trips/{tripId}/agent/run` | 연결 코드는 구형 미사용 화면에만 존재 | 활성 `/trip/places`에 AI 에이전트 실행 연결 |
| P1 | AI 에이전트 실행 결과 | 활성 화면에서 표시하지 않음 | `summary`, 도구 단계, 실행 방식 표시 |
| P1 | `GET /api/matches/{matchId}` | 후보 목록 데이터로 상세 화면 구성 | 매칭 상세 직접 조회 연결 및 응답 필드 확장 |
| P1 | `GET /api/match-requests/{requestId}` | 서비스 메서드만 존재 | 알림에서 요청 상세로 직접 이동하는 화면 연결 |
| P1 | `DELETE /api/me/matches/{matchId}` | 서비스 메서드만 있고 사용자 동작 없음 | 종료된 매칭 기록 숨김 버튼 연결 |
| P1 | `POST /api/matches/{matchId}/chat-room` | 서비스 메서드만 존재 | 기존 매칭의 채팅방 생성·복구 경로 연결 |
| P2 | `GET /api/tti/types` | 프론트에서 호출하지 않음 | TTI 유형 사전과 결과 설명에 활용 |
| P2 | `POST /api/trips/{tripId}/attractions/generate` | 활성 화면은 `generate-public` 사용 | 레거시 API 사용 여부를 결정하고 미사용 시 제거 |
| P2 | `GET /api/users/me` | 프론트는 `/api/auth/me` 사용 | 중복 사용자 조회 API 정리 |

## 3. 프론트 화면은 있지만 백엔드가 없는 기능

| 우선순위 | 프론트 화면/기능 | 현재 동작 | 필요한 백엔드 |
| --- | --- | --- | --- |
| P0 | 양보 범위 조사서 | 입력 체험만 가능하며 저장하지 않음 | 사용자별 비공개 저장·제출 상태·공개 시점 |
| P0 | Odd Rule | 선택 체험만 가능하며 합의 상태를 만들지 않음 | 제안·상대 동의·최종 규칙·버전 이력 |
| P0 | AI 조정 제안 확정 | 조정 문장 생성만 가능 | AI 결과를 공동 합의안으로 제안·수락하는 API |
| P0 | 장소 개인 투표 | 모달에서 선택할 수 있지만 전송하지 않음 | 사용자별 `want`·`neutral`·`skip` 저장 및 집계 |
| P0 | 휴대전화 본인확인 | 준비 중 안내만 표시 | SMS 발송·OTP 검증·만료·재시도·인증 상태 |
| P1 | 일정 항목 수정 | 준비 중 안내만 표시 | 항목 PATCH·DELETE·순서 변경·revision 충돌 처리 |
| P1 | 알림 유형별 설정 | 준비 중 안내만 표시 | 사용자별 알림 유형 수신 설정 |
| P1 | 모바일 Push | 준비 중 안내만 표시 | 기기 토큰 등록·철회·APNs/FCM 발송 결과 |
| P1 | D-1 리마인더 | 준비 중 안내만 표시 | 예약 작업·시간대 처리·중복 방지 |
| P1 | 프로필 이미지 등록 | 외부 이미지 URL 입력만 가능 | 파일 업로드·스토리지·크기 및 콘텐츠 검사 |
| P1 | 비밀번호 변경 | 미지원 안내 | 현재 비밀번호 확인·새 비밀번호 변경 API |
| P1 | 비밀번호 재설정 | 화면 없음 | 이메일 확인·재설정 토큰·만료 처리 |
| P1 | 이메일 변경·인증 | 화면 없음 | 이메일 인증·중복 확인·변경 API |
| P2 | 관리자 관광지 | 정적 예시 데이터 | 관광지 조회·CRUD·외부 데이터 재수집 |
| P2 | 관리자 TTI 편집 | 실제 질문 조회만 가능 | 질문·유형 CRUD·활성 상태·버전 배포 |
| P2 | 관리자 운영 상태 | 고정 예시 데이터 | health·latency·`checkedAt`·장애 기록 API |

## 4. 양쪽에 구현됐지만 연결이 불완전한 기능

| 우선순위 | 영역 | 문제 | 필요한 조치 |
| --- | --- | --- | --- |
| P0 | 매칭 본인확인 | 매칭 자격은 TTI·동의만 검사 | 실제 성인·본인인증 상태를 자격 조건에 포함 |
| P0 | 매칭 나이대 | `ageRange`가 항상 빈 문자열 | 생년·나이대 또는 인증 결과 모델 연결 |
| P0 | 여행 딥링크 | `/trip/overview`에 여행 ID가 없음 | `/trips/:tripId/overview` 형태로 변경 |
| P0 | 장소 실시간 동기화 | 저장·제외 변경이 상대에게 즉시 전달되지 않음 | 장소 변경 WebSocket 이벤트 추가 |
| P0 | 일정 실시간 동기화 | 생성·재생성이 상대에게 즉시 전달되지 않음 | 일정 revision WebSocket 이벤트 추가 |
| P1 | 조율 알림 | 합의안 변경이 WebSocket에만 존재 | 오프라인 사용자를 위한 영구 알림 생성 |
| P1 | 안전정보 출처 | mock과 실제 데이터를 응답에서 구분하지 못함 | `source`, `sourceStatus`, `updatedAt` 추가 |
| P1 | 안전정보 갱신 | 최초 생성 후 자동 갱신 없음 | 주기 갱신·만료·중복 방지 구현 |
| P1 | 지도 경로 | Google과 fallback 결과를 구분할 수 없음 | 이동 정보에 `source` 필드 추가 |
| P1 | AI 결과 | 실제 Gemini와 fallback 결과를 구분할 수 없음 | `mode`·`source` 필드 통일 |
| P2 | WebSocket | 채팅용과 조율용 연결이 중복될 수 있음 | 단일 연결·이벤트 버스로 통합 |
| P2 | 알림 낙관 처리 | 읽음 처리 실패 시 항목 상태 복구가 불완전함 | 실패 시 목록까지 서버 상태로 재동기화 |
